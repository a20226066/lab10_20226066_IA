Pregunta 1. Crear una pecera con la API DOM

La función crearPecera(x) construye un tablero de x filas y x columnas creando sus celdas desde JavaScript, sin escribirlas una a una en el HTML.

6 × 6 = 36 celdas

Haz clic en una celda para resaltarla: es otro ejemplo de manipulación del DOM.

API utilizada: document.createElement(), appendChild(), getElementById() y replaceChildren().
